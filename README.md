# 🛒 WebStore

**WebStore** är ett Java-baserat webbprojekt byggt med **Spring MVC** och **JSP**, som visar grunderna i att bygga en enkel men strukturerad webbutik med modern konfiguration utan XML.

## 🌐 Funktioner

- Välkomstsida med hälsningsmeddelande
- Spring MVC-konfiguration med Java-klasser
- Separering av logik (Controller) och presentation (JSP)
- Enkel vy-resolver för att ladda sidor från `/WEB-INF/jsp`

## 🧰 Teknikstack

| Teknik | Användning |
|--------|------------|
| Java | Backendlogik |
| Spring MVC | Web framework |
| JSP | Dynamisk HTML för presentation |
| Maven | Byggverktyg och beroendehantering |
| Eclipse | Utvecklingsmiljö (projektfiler inkluderade) |
